# AENAON ERP — 9.5A.2 Back Office Layout Refinement

## Σκοπός
Ομοιόμορφη και συμπαγής παρουσίαση των σελίδων **Κατάλογος** και **Επισκόπηση**, χωρίς επαναλαμβανόμενους τίτλους ή απώλεια λειτουργιών.

## Σύντομη περιγραφή
Η ενεργή θέση του χρήστη παραμένει ορατή στο επάνω μενού πλοήγησης (Topbar). Ο Κατάλογος προβάλλει τις καρτέλες και αμέσως μετά τον πίνακα της επιλεγμένης ενότητας. Η Επισκόπηση ξεκινά από την επιλογή επιχείρησης και καταστήματος.

{% hint style="info" %}
Η αλλαγή αφορά αποκλειστικά διάταξη, CSS και ελέγχους εμφάνισης. **Δεν προστίθενται migrations**, δεν μεταβάλλεται η βάση δεδομένων και δεν αλλάζουν τα συμβόλαια των APIs.
{% endhint %}

## Προϋποθέσεις
- Ενεργός λογαριασμός AENAON ERP με δικαίωμα πρόσβασης στο Back Office.
- Συμβατός σύγχρονος browser με ενεργοποιημένο JavaScript για τις εμπλουτισμένες επιλογές του Καταλόγου.
- Εγκατεστημένο το .NET SDK που ορίζει το `global.json` για τοπική εκτέλεση.
- SQL Server και ρυθμίσεις ανάπτυξης όπως έχουν ήδη διαμορφωθεί στο έργο.

## Διαχείριση Καταλόγου
1. Ανοίξτε **Κατάλογος** από το αριστερό μενού ή την Επισκόπηση.
2. Επιλέξτε **Προϊόντα**, **Υπηρεσίες** ή **Κατηγορίες**.
3. Στην επικεφαλίδα του πίνακα βλέπετε το όνομα της επιλεγμένης ενότητας και, όταν υπάρχουν εγγραφές, το πλήθος τους.
4. Αν έχετε δικαιώματα διαχείρισης, χρησιμοποιήστε το δεξί κουμπί **Νέο προϊόν**, **Νέα υπηρεσία** ή **Νέα κατηγορία** αντίστοιχα.
5. Συνεχίστε να χρησιμοποιείτε αναζήτηση, φίλτρα, ταξινόμηση, σελιδοποίηση, επεξεργασία και δημιουργία όπως προηγουμένως.

{% hint style="success" %}
Ο σύνδεσμος δημιουργίας εξακολουθεί να δημιουργείται από την ίδια υφιστάμενη μέθοδο, με το ισχύον πλαίσιο επιχείρησης/καταστήματος.
{% endhint %}

### Δικαιώματα
- **Owner:** βλέπει το κουμπί δημιουργίας μέσα στην κάρτα του πίνακα.
- **Μόνο ανάγνωση:** βλέπει την ένδειξη «Μόνο ανάγνωση», όχι κουμπί δημιουργίας.
- Η εξουσιοδότηση στον server παραμένει απαραίτητη· η απόκρυψη κουμπιού δεν αποτελεί μηχανισμό ασφάλειας.

## Επισκόπηση
1. Ανοίξτε **Επισκόπηση**.
2. Στην ενότητα **Επιχείρηση & κατάστημα** επιλέξτε την επιχείρηση με την οποία θα εργαστείτε.
3. Επιλέξτε το αντίστοιχο κατάστημα.
4. Η ενεργή επιλογή εμφανίζεται επίσης στο Topbar.
5. Χρησιμοποιήστε τη σύντομη ενότητα **Κατάλογος** για πρόσβαση στα προϊόντα, τις υπηρεσίες και τις κατηγορίες.

Οι ενδείξεις ελλείψεων ή μη έγκυρων επιλογών επιχειρήσεων/καταστημάτων εξακολουθούν να εμφανίζονται.

## Προσβασιμότητα και κινητές συσκευές
- Κάθε βασική σελίδα διαθέτει ορατό κύριο τίτλο `h1` στην ενεργή ενότητα.
- Τα χειριστήρια παραμένουν προσβάσιμα με **Tab**, **Shift+Tab** και **Enter**.
- Το κουμπί δημιουργίας μεταφέρεται σε πλήρες διαθέσιμο πλάτος σε μικρές οθόνες.
- Η οπτική ένδειξη εστίασης διατηρείται για την κύρια ενέργεια.
- Οι υπάρχουσες δυνατότητες επιλογής επιχείρησης/καταστήματος εκτελούνται μέσω των ίδιων ασφαλών POST φορμών με CSRF προστασία.

## Προέλεγχος πριν την αναβάθμιση
1. Επιβεβαιώστε το τελευταίο επιτυχές backup της βάσης, σύμφωνα με την πολιτική της εταιρείας. Δεν απαιτείται νέο backup για αλλαγή CSS, αλλά η γενική πολιτική ανάκτησης ισχύει.
2. Βεβαιωθείτε ότι το `git status` είναι καθαρό.
3. Καταγράψτε την τρέχουσα έκδοση που λειτουργεί.

## Αντιμετώπιση προβλημάτων
**Δεν εμφανίζεται το κουμπί δημιουργίας:** Ελέγξτε πρώτα αν ο χρήστης διαθέτει ρόλο Owner στο επιλεγμένο tenant. Ο ρόλος δεν άλλαξε.

**Η επιλογή καταστήματος δεν επιμένει:** Ελέγξτε την υφιστάμενη ροή επιλογής, τις απαντήσεις POST και τα σχετικά logs· δεν τροποποιήθηκε η λογική αποθήκευσης.

**Η παλιά διάταξη εξακολουθεί να εμφανίζεται:** Κάντε πλήρη ανανέωση στον browser και επιβεβαιώστε ότι αναπτύχθηκαν τα νέα στατικά CSS assets.

**Το κουμπί μεταφέρεται σε νέα γραμμή:** Σε μικρές οθόνες είναι αναμενόμενο. Πρέπει να παραμένει πλήρως ορατό και εύχρηστο.
