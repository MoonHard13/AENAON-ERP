# AENAON ERP — Mobile Back Office Responsive UX

## Σκοπός

Ανασχεδιασμός της προβολής του Back Office σε κινητά ώστε το Dashboard, ο Κατάλογος, οι Τιμοκατάλογοι και η καρτέλα τιμών/ιστορικού να είναι **πλήρως αναγνώσιμα και λειτουργικά**, χωρίς περικομμένα κουμπιά ή την ανάγκη οριζόντιας κύλισης ολόκληρης της σελίδας.

{% hint style="info" %}
Το βήμα αλλάζει μόνο Blazor markup, CSS και αυτοματοποιημένους ελέγχους responsive συμπεριφοράς. **Δεν προστίθεται migration, δεν μεταβάλλονται τιμές ή φορολογικά δεδομένα και δεν εκτελείται SQL write.** Παραμένουν οι υπάρχοντες έλεγχοι Tenant, Owner/Member και antiforgery.
{% endhint %}

## Προϋποθέσεις

Τρέχον Development `main` μετά από review/Squash merge του PR, λειτουργικό HTTPS AENAON ERP και χρήστης με Tenant Read/Manage. Η μόνη migration που αφορά το προηγούμενο βήμα είναι `20261114163000_PriceListAuditHistory`· αυτή η αλλαγή **δεν την εφαρμόζει**.

## Χρήση σε κινητό / Chrome DevTools

1. Εκκινήστε το AENAON ERP και συνδεθείτε με εξουσιοδοτημένο λογαριασμό.
2. Στο Chrome ανοίξτε **F12 → Ctrl+Shift+M → Responsive**.
3. Δοκιμάστε πλάτη **375, 390, 430, 650, 768 και 1366 px** με ύψος τουλάχιστον 667 px.
4. Στο Dashboard ελέγξτε brand, mobile μενού, επιλογή επιχείρησης/καταστήματος και κάρτες.
5. Στον Κατάλογο ελέγξτε Προϊόντα, Υπηρεσίες, Κατηγορίες, φίλτρα, sorting και όλες τις κάρτες, καθώς και πλήρη εμφάνιση των ενεργειών Επεξεργασία.
6. Στους Τιμοκαταλόγους ελέγξτε τα κουμπιά **Προεπισκόπηση τιμής** και **Νέος τιμοκατάλογος**· δεν πρέπει να κόβονται.
7. Σε υπάρχοντα τιμοκατάλογο ελέγξτε αναζήτηση, sorting, πεδία ποσών, αποθήκευση και confirmation αφαίρεσης τιμής. Η αφαίρεση απαιτεί την υπάρχουσα ρητή επιβεβαίωση.
8. Δοκιμάστε **Light/Dark**, portrait/landscape, 200% zoom και πλοήγηση με Tab/Enter.

{% hint style="warning" %}
Όπως και στο desktop, η πλοήγηση σε άλλη ταξινόμηση ή σελίδα δεν αποθηκεύει αυτόματα μη υποβλημένες τιμές. Πρώτα κάντε **Αποθήκευση τιμών σελίδας**.
{% endhint %}

## Ταξινόμηση και διατήρηση δεδομένων

Οι επιλογείς στο mobile χρησιμοποιούν την **ίδια υπάρχουσα** υπηρεσία SQL ταξινόμησης και τα URL `sort`/`desc` με το desktop. Στο desktop οι επιλογείς είναι κρυμμένοι οπτικά, αλλά συνεχίζουν να υποβάλλουν τη μοναδική έγκυρη επιλογή όταν γίνεται αναζήτηση. Δεν παράγονται διπλές παράμετροι `sort` ή `desc`. Στο mobile, η ταξινόμηση και η κατεύθυνση εφαρμόζονται πατώντας **Αναζήτηση**. Η ταξινόμηση δεν αλλάζει τον κωδικό ή την τιμή προϊόντος.

## Χρήση CLI

Οι λειτουργίες CLI και τα exit codes **δεν άλλαξαν**. Για ανάγνωση τιμοκαταλόγου:

```powershell
dotnet run --project src/Aenaon.Api --launch-profile https -- --manage-price-lists --username admin --tenant-id "TENANT_GUID" --confirm-database AenaonERP_Dev --action items --id "PRICE_LIST_GUID" --sort code --dry-run
```

## Έλεγχος εγκατάστασης και επιστροφής

```powershell
git switch main
git pull --ff-only origin main
dotnet restore AenaonERP.slnx --locked-mode
dotnet test AenaonERP.slnx --configuration Release --filter "TestCategory!=SqlServer"
dotnet run --project src/Aenaon.Api --launch-profile https -- --migrate-database --dry-run
dotnet run --project src/Aenaon.Api --launch-profile https
```

Η βελτίωση είναι αποκλειστικά frontend/SSR και δεν απαιτεί νέο SQL migration ή backup για εφαρμογή **αυτών** των αλλαγών. Για επιστροφή σε προηγούμενη έκδοση, επαναφέρετε τον προηγούμενο δημοσιευμένο κώδικα/commit: δεν υπάρχει ανάγκη rollback SQL.

## Έλεγχοι ποιότητας

- HTTP tests για τις κάρτες, τα `data-label`, τα native mobile sort controls και την απουσία διπλών GET sort fields.
- Πραγματικό Chromium/CDP smoke με τα υπάρχοντα CSS και σχετικό responsive fixture σε 375/390/430/768/1366 px: ελέγχει width overflow, ύψος mobile brand, προσβασιμότητα actions και μετατροπή των rows σε κάρτες.
- GitHub Actions Linux/Windows με format, build, unit/integration, απομονωμένο SQL Server 2022, publish και HTTPS smoke.
- Οι browser geometry tests είναι **αυτοματοποιημένο fixture**, όχι απόδειξη οπτικής αποδοχής της πραγματικής σελίδας. Απαιτείται επιπλέον χειροκίνητη δοκιμή με το AENAON ERP.

## Troubleshooting / best practices

**Δεν βλέπω τις αλλαγές:** ελέγξτε ότι το PR έχει γίνει merge, πραγματοποιήθηκε `git pull --ff-only` και επανεκκινήθηκε το API. Χρησιμοποιήστε `Ctrl+F5` για ανανέωση cached CSS.

**Κρυμμένα desktop table headers στο κινητό:** τα mobile native φίλτρα επιτρέπουν sorting χωρίς οριζόντια κύλιση. Οι επικεφαλίδες παραμένουν στον DOM/accessibility tree και εμφανίζονται όταν αποκτήσουν πληκτρολογιακή εστίαση.

**Μη εμφανιζόμενες τιμές:** ελέγξτε την κατάσταση Tenant/store, τη σωστή επιλογή τιμοκαταλόγου και το application log. Μην διορθώνετε εικαστικά την DB.

**Πραγματικό κινητό:** προτιμήστε ασφαλές HTTPS staging ή έμπιστο LAN με σωστό πιστοποιητικό· ποτέ δημόσια έκθεση της Development βάσης για απλή δοκιμή.
