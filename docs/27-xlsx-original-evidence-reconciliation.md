# Aenaon ERP — 9.3C.3B.3: Ανεξάρτητη Συμφωνία Πρωτότυπου XLSX και Πλήρους JSON

## 1. Σκοπός

Μετά την πλήρη εξαγωγή του αρχείου «Συνδυασμοί χαρακτηρισμών» της ΑΑΔΕ, ο έλεγχος **τεχνικής συμφωνίας** είναι απαραίτητος πριν αρχίσει οποιαδήποτε προσπάθεια ερμηνείας φορολογικών κανόνων. Η διαδικασία διαβάζει **ξανά το πραγματικό XLSX** και συγκρίνει το αποτέλεσμα ανεξάρτητα με το ήδη δημιουργημένο JSON.

{% hint style="danger" %}
Η τεχνική συμφωνία **δεν** είναι φορολογική έγκριση, πιστοποίηση αυθεντικότητας από την ΑΑΔΕ, ούτε επιβεβαίωση συμβατότητας IMPACT. Η ημερομηνία ισχύος, τα ειδικά παραστατικά, τα B2G πεδία, ο ΦΠΑ και οι εξαιρέσεις απαιτούν διαφορετικούς ελέγχους. `IsClassificationMatrixVerified`, `IsImpactContractValidated`, `IsFiscalRuleApproved` και `CanIssueFiscalDocument` παραμένουν πάντα **false**.
{% endhint %}

## 2. Επίσημες πηγές (10/11/2026)

- [ΑΑΔΕ: Τεχνικές προδιαγραφές – Εκδόσεις myDATA](https://www.aade.gr/mydata/tehnikes-prodiagrafes-ekdoseis-mydata) — έκδοση **2.0.2** και ξεχωριστό «Συνδυασμοί χαρακτηρισμών (αρχείο xls)».
- [Αρχείο XLSX συνδυασμών 2.0.2](https://www.aade.gr/sites/default/files/2026-09/syndiasmoi_xaraktirismwn_v2.0.2_0.xlsx).
- [IMPACT: Classification/Payment Method Codes](https://developers.s1ecos.com/classification-payment-method-codes-iapr-869832m0).
- [IMPACT: VAT/TAX Codes](https://developers.s1ecos.com/vat-tax-codes-869826m0).
- [IMPACT: Conditional Fields](https://developers.s1ecos.com/minimum-conditional-fields-869822m0).

Απαιτείται **ανθρώπινη επιβεβαίωση** ότι το τοπικό αρχείο έχει ληφθεί από την παραπάνω επίσημη πηγή και δεν έχει αλλοιωθεί. Ένα SHA-256 συγκρίνει bytes, αλλά δεν εγγυάται ότι ο χρήστης διάλεξε σωστό αρχείο.

## 3. Τι επαληθεύεται

Η `FiscalXlsxEvidenceReconciliationService` ξαναδιαβάζει το XLSX με τον υφιστάμενο ασφαλή OOXML inspector και αναπαράγει το αναμενόμενο export **χωρίς εμπιστοσύνη σε μετρητές του JSON**.

| Στοιχείο | Έλεγχος |
| --- | --- |
| SHA-256 | Ακριβές αποτύπωμα των bytes πρωτοτύπου, όχι απλή τιμή κειμένου από JSON |
| FileSizeBytes | Ίδιο μήκος πραγματικού XLSX και τιμής JSON |
| SheetCount | Ίδιο πλήθος και ίδια σειρά φύλλων |
| NonEmptyCellCount / ExportedCellCount | Συμφωνία ανά φύλλο και συνολικά |
| `Sheets[].Cells[]` | Ίδια σειρά, διεύθυνση, πλήρες κείμενο, formula flag και style index |
| `Sheets[].MergedRanges[]` | Ίδιες δηλωμένες συγχωνεύσεις |
| `ClassificationEvidence.CandidatePairs[]` | Ταυτόσημη αναπαραγωγή υποψήφιων ζευγών, προελεύσεων και κατευθύνσεων |
| `ClassificationEvidence.RequiresReview[]` | Ταυτόσημες παρατηρήσεις και λόγοι ανθρώπινου ελέγχου |
| Flags φορολογικής ενεργοποίησης | Υποχρεωτικά **false**, αλλιώς απόρριψη |

Όλες οι αποκλίσεις οδηγούν σε fail-closed απόρριψη. Δεν υπάρχει σύστημα «διορθώσεων» του JSON κατά την επαλήθευση, ούτε αποθήκευση στη βάση.

## 4. Πραγματικό αποτέλεσμα προηγούμενης εξαγωγής

Κατά τον έλεγχο του αρχείου `AADE_myDATA_FullEvidence.json` που παρείχε ο τεχνικός, διαπιστώθηκαν:

| Μετρική | Τιμή |
| --- | ---: |
| Φύλλα | **53** |
| Κελιά | **2.373/2.373** |
| Υποψήφια ζεύγη εσόδων | **314** |
| Υποψήφια ζεύγη εξόδων | **1.089** |
| Σύνολο υποψήφιων ζευγών | **1.403** |
| Εγγραφές προς ανθρώπινο έλεγχο | **254** |
| Συγχωνευμένες περιοχές | **206** |

**Εσωτερική συμφωνία JSON: επιβεβαιωμένη** κατά τον αρχικό έλεγχο. Η επαλήθευση έναντι του **αρχικού XLSX** είναι το αντικείμενο της νέας CLI λειτουργίας και πρέπει να εκτελεστεί στον υπολογιστή που διαθέτει το πρωτότυπο.

{% hint style="warning" %}
Υποψήφια ζεύγη που εξαρτώνται από άλλα παραστατικά (ενδεικτικά 1.6, 2.4, 5.1), οδηγίες προηγούμενης/επόμενης χρήσης, καθώς και εγγραφές «Δεν ενημερώνει E3», **δεν μετατρέπονται σε εγκεκριμένους κανόνες**. Οι υποψήφιες αντιστοιχίσεις B/C (έσοδα) και E/F (έξοδα) απαιτούν επιβεβαίωση διάταξης, συγχωνεύσεων και μορφοποίησης.
{% endhint %}

## 5. Προϋποθέσεις

- Το εργαλείο λειτουργεί αποκλειστικά σε περιβάλλον **Development**.
- Το αρχείο XLSX πρέπει να είναι το **ακριβές αρχικό** αρχείο που χρησιμοποιήθηκε για το `--export-json`.
- Το JSON πρέπει να υπάρχει τοπικά, να είναι πλήρες και **χωρίς μεταγενέστερη επεξεργασία**.
- .NET SDK από `global.json`. Δεν απαιτείται σύνδεση SQL Server ή IMPACT.

## 7. Ανεξάρτητη επαλήθευση

Από PowerShell:

```powershell

```

Αν το πραγματικό XLSX έχει διαφορετικό όνομα, διόρθωσε τη διαδρομή χωρίς μετονομασία του ίδιου του τεκμηρίου.

**Επιτυχής έξοδος** (οι μετρικές εξαρτώνται από το περιεχόμενο):

```text
ΤΕΧΝΙΚΗ ΣΥΜΦΩΝΙΑ ΠΡΩΤΟΤΥΠΟΥ XLSX / JSON: ΕΠΙΤΥΧΗΣ
SHA-256: ...
Φύλλα: 53
Κελιά: 2373
Υποψήφια ζεύγη: 1403
Παρατηρήσεις προς έλεγχο: 254
Δεν επιβεβαιώθηκε προέλευση από ΑΑΔΕ, φορολογική εγκυρότητα ή IMPACT συμβατότητα.

```

Η επιτυχία αποδεικνύει **τεχνική ταύτιση του συγκεκριμένου αρχείου XLSX και του JSON**, όχι την εγκυρότητα φορολογικών συνδυασμών.

## 8. Αντιμετώπιση προβλημάτων

| Κωδικός | Αιτία / ενέργεια |
| --- | --- |
| `fiscal.xlsx.reconciliation.invalid` | Άκυρο JSON, ελλιπή στοιχεία, άγνωστα πεδία, ψευδής ένδειξη έγκρισης, μεγαλύτερο από 32 MiB |
| `fiscal.xlsx.reconciliation.mismatch` | Έχουν αλλάξει κελιά, SHA-256, φύλλα, συγχωνεύσεις ή παρατηρήσεις· επίλεξε το σωστό αρχικό XLSX και κάνε νέα εξαγωγή |
| `fiscal.xlsx.structure.invalid` | Το πρωτότυπο XLSX δεν είναι ασφαλές ή σωστό OOXML· ακολούθησε το [manual δομικής επιθεώρησης](25-official-xlsx-structure-inspection.md) |
| I/O error | Έλεγξε διαδρομές, δικαιώματα, κλειδωμένα αρχεία, δίσκο |
| Ακύρωση | `Ctrl+C`, χωρίς αλλαγές σε δεδομένα |

Κωδικοί εξόδου: **0** τεχνική συμφωνία, **1** I/O, **2** αποτυχία επαλήθευσης/δομής, **130** ακύρωση.

Τα logs περιλαμβάνουν μόνο το αποτέλεσμα και τις μετρικές, όχι το περιεχόμενο φορολογικών κελιών.

## 9. Πότε χρησιμοποιείται και πότε όχι

**Χρησιμοποιείται:** μετά από κάθε νέα εξαγωγή JSON και πριν από επίσημο review, αλλαγή έκδοσης ή δοκιμή κανόνων. Η ίδια διαδικασία πρέπει να επαναληφθεί για κάθε νέο επίσημο XLSX.

**Δεν χρησιμοποιείται:** ως έγκριση `FiscalTaxMappings`, νομική επικύρωση, επιβεβαίωση Β2G/IMPACT payload ή δικαίωμα έκδοσης.

## 10. Ασφάλεια, rollback και συντήρηση

- Τα δύο αρχεία είναι read-only· η λειτουργία δεν δημιουργεί νέα αρχεία.
- Δεν αλλάζει schema, migration, identity permissions, reference registry, provider connections ή παραγωγικό SQL.
- **Rollback:** Git revert του συγκεκριμένου PR, χωρίς επέμβαση στη βάση.
- Αρχειοθέτησε πρωτότυπο και JSON με καταγεγραμμένο SHA-256, ημερομηνία λήψης και ελεγχόμενα δικαιώματα.
