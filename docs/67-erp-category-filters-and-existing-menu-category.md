## 1. Σκοπός

Ο Menu Builder προσφέρει πλέον ενιαία αναζήτηση **ονόματος/κωδικού είδους και κατηγορίας ERP**. Τα αποτελέσματα εμφανίζονται ως καθαρές, συμπαγείς γραμμές με checkbox αριστερά και προαιρετικό `+` μεμονωμένης προσθήκης δεξιά. Διατηρούνται η πολλαπλή επιλογή, η ένδειξη πλήθους και η μία ασφαλής αποθήκευση.

Επιπλέον επιτρέπεται η επιλογή μιας **ήδη υπάρχουσας ενεργής κατηγορίας ERP** και η προσθήκη της στη ρίζα ή κάτω από επιλεγμένη γονική κατηγορία. Πρόκειται για σύνδεση της υπάρχουσας κατηγορίας, όχι για δημιουργία νέας εγγραφής ERP.

## 2. Προϋποθέσεις και όρια

- Ενημερωμένη Development εφαρμογή στον σωστό Tenant/Store.
- Επιλεγμένο προσχέδιο μενού. Owner για αλλαγές, Member μόνο για ανάγνωση.
- Κατηγορίες/είδη υπάρχουν στο ERP Catalog και είναι ενεργά.
- Το φίλτρο εμφανίζει μόνο ενεργές ERP κατηγορίες. **Η επιλογή κατηγορίας φιλτράρει ακριβώς τα είδη της συγκεκριμένης κατηγορίας**, όχι αυτομάτως τα είδη όλων των υποκατηγοριών. Για είδη υποκατηγορίας την επιλέγετε χωριστά.
- Το φίλτρο κειμένου συνεχίζει να εφαρμόζει **αναζήτηση από την αρχή** του ονόματος ή κωδικού. Τα δύο φίλτρα συνδυάζονται με **AND**. Η αναζήτηση επιστρέφει έως 50 ενεργά είδη κάθε φορά.
- Απαιτείται μόνο υπάρχον schema #13, **καμία νέα migration**.

## 3. Αναζήτηση ειδών με φίλτρο κατηγορίας

1. Επιλέξτε μενού και μεταβείτε στην αρχική οθόνη ή μέσα σε κατηγορία/υποκατηγορία.
2. Ανοίξτε **Επιπλέον είδη από ERP Catalog**.
3. Συμπληρώστε **Αναζήτηση είδους ή κωδικού** αν χρειάζεται.
4. Από το φίλτρο **Κατηγορία ERP** επιλέξτε μια ενεργή κατηγορία ή **Όλες οι κατηγορίες**.
5. Πατήστε **Αναζήτηση**. Το επιλεγμένο φίλτρο διατηρείται στη διεύθυνση URL μαζί με το όνομα/κωδικό όσο χρησιμοποιείται η πλοήγηση GET.
6. Τα αποτελέσματα εμφανίζονται σε γραμμές πλήρους πλάτους. Πατήστε στην περιγραφή ή στο checkbox για να επιλέξετε είδος, **Επιλογή όλων** για την ορατή λίστα ή **Καθαρισμός**.
7. Πατήστε **Προσθήκη επιλεγμένων**. Η συναλλαγή είναι atomic και προστατεύεται από Owner/CSRF/revision/RequestId. Το κουμπί `+` παραμένει για ένα είδος ανά ενέργεια.
8. Ανανεώστε το μενού και επιβεβαιώστε την αποθήκευση και τη σωστή θέση. Είδη ήδη προστιθέμενα στο **τρέχον επίπεδο του μενού** εμφανίζουν ένδειξη **Προστέθηκε** αντί για checkbox.

Η επιλογή δεν μεταφέρεται σε επόμενη αναζήτηση (GET). Για μεγαλύτερο πλήθος εκτελέστε διαδοχικά batches. Αν το φίλτρο δεν έχει αποτέλεσμα, η λίστα δείχνει σαφές κενό αποτέλεσμα.

## 4. Προσθήκη υπάρχουσας κατηγορίας ERP

1. Μεταβείτε στο επίπεδο του μενού όπου θέλετε την κατηγορία.
2. Στο πλέγμα κατηγοριών επιλέξτε **Υπάρχουσα κατηγορία ERP**. Η ενέργεια εμφανίζεται μόνο για Owner και όταν υπάρχει ενεργή ERP κατηγορία που **δεν είναι ήδη συνδεδεμένη με το ίδιο μενού**.
3. Από τη λίστα επιλέξτε κατηγορία με **Όνομα (Κωδικός)**.
4. Πατήστε **Προσθήκη από ERP**. Η κατηγορία συνδέεται στο **τρέχον επίπεδο**: στη ρίζα ή ως παιδί της επιλεγμένης κατηγορίας.
5. Η σύνδεση κρατά το πραγματικό `CatalogCategoryId`, ενώ αποκτά διαφορετικό `MenuDraftCategory.Id`, άρα δεν μεταβάλλει την κύρια εγγραφή ERP.
6. Επιλέξτε χωριστά τα επιθυμητά είδη μέσω του φίλτρου **Κατηγορία ERP**. **Δεν πραγματοποιείται σιωπηρή εισαγωγή όλων των ειδών/υποκατηγοριών** της πηγής.
7. Μετά την αποθήκευση ελέγξτε τα breadcrumbs, τη θέση, το νέο revision και την επιμονή μετά από F5.

Μια ERP κατηγορία μπορεί να συνδεθεί **μία φορά ανά μενού** και σε διαφορετικά μενού ανεξάρτητα. Αν αφαιρεθεί από το προσχέδιο, μπορεί να επανασυνδεθεί. Απενεργοποιημένες ή ξένου Tenant πηγές απορρίπτονται από το backend. Η επιλογή γονέα άλλου μενού επίσης απορρίπτεται.

## 5. Πεδία και έλεγχοι ασφάλειας

| Πεδίο | Σκοπός |
| --- | --- |
| `catalogCategoryId` (GET) | Προαιρετικό φίλτρο ERP κατηγορίας για την αναζήτηση ειδών |
| `search` (GET) | Πρόθεμα ονόματος/κωδικού, έως 80 χαρακτήρες |
| `sourceCatalogCategoryId` (POST) | Υποχρεωτική ταυτότητα υπάρχουσας ERP κατηγορίας |
| `parentCategoryId` (POST) | Προαιρετικός γονέας **του επιλεγμένου μενού** |
| `menuId`, `tenantId`, `storeId` | Πεδίο πρόσβασης του χρήστη και απομόνωση |
| `expectedRevision`, `requestId` | Προστασία concurrency και idempotent retries |
| `__RequestVerificationToken` | Υποχρεωτική CSRF προστασία σε HTTPS POST |

Η εφαρμογή επιβεβαιώνει server-side ενεργή ERP κατηγορία, ίδιο Tenant, μη επαναχρησιμοποιημένη σύνδεση στο ίδιο μενού, σωστό parent scope και τα όρια 10.000 κατηγοριών. Ο σύνθετος SQL FK και το unique filtered index παρέχουν επιπλέον προστασία.

## 6. CLI/CMD και συντομεύσεις

Οι αναζητήσεις και η σύνδεση κατηγορίας προσφέρονται μέσω της ίδιας κοινής υπηρεσίας.

~~~powershell
# Προβολή ενεργών ERP κατηγοριών της επιχείρησης, χωρίς εγγραφή.
dotnet run --project src/Aenaon.Api --launch-profile https -- --manage-menus --username admin --tenant-id "TENANT_GUID" --confirm-database AenaonERP_Dev --action catalog-categories --dry-run

# Προβολή ειδών συγκεκριμένης ERP κατηγορίας.
dotnet run --project src/Aenaon.Api --launch-profile https -- --manage-menus --username admin --tenant-id "TENANT_GUID" --confirm-database AenaonERP_Dev --action catalog --catalog-category-id "CATALOG_CATEGORY_GUID" --search "P" --dry-run

# Μόνο προεπισκόπηση σύνδεσης ERP κατηγορίας στο μενού (όχι SQL APPLY).
dotnet run --project src/Aenaon.Api --launch-profile https -- --manage-menus --username admin --tenant-id "TENANT_GUID" --confirm-database AenaonERP_Dev --action link-catalog-category --menu-id "MENU_GUID" --source-catalog-category-id "CATALOG_CATEGORY_GUID" --expected-revision 1 --dry-run
~~~

Για προσθήκη κάτω από κατηγορία περνάτε επίσης `--parent-category-id "MENU_CATEGORY_GUID"`. Οι πραγματικές αλλαγές απαιτούν `--apply` σε **εξουσιοδοτημένο, απομονωμένο test menu** και όχι απευθείας σε Production. Ο κωδικός χρήστη εισάγεται μόνο διαδραστικά, ποτέ σε command argument.

**Πληκτρολόγιο:** Tab/Shift+Tab πλοήγηση, Space επιλογή checkbox, Enter για αναζήτηση/υποβολή, accesskey F για αναζήτηση και Ctrl+S/Cmd+S όταν η εστίαση βρίσκεται στη φόρμα πολλαπλής επιλογής.

## 8. Αντιμετώπιση προβλημάτων και best practices

**Δεν εμφανίζονται είδη:** ελέγξτε αν η κατηγορία έχει ενεργά είδη **απευθείας** συνδεδεμένα με αυτήν. Επιλέξτε χωριστά υποκατηγορία για τα είδη της. Ελέγξτε τυχόν όρο κειμένου.

**Δεν εμφανίζεται η κατηγορία προς σύνδεση:** πιθανόν είναι ανενεργή ή ήδη συνδεδεμένη με το ίδιο μενού. Δεν επιτρέπονται δύο αντίγραφα του ίδιου ERP CategoryId στο ίδιο μενού.

**Αποτυχία αποθήκευσης:** ανανεώστε για την τρέχουσα revision και ελέγξτε Owner δικαιώματα, συνδεδεμένο Tenant και τρέχον parent. Μην διορθώνετε δεδομένα με χειροκίνητο SQL.

**Πότε χρησιμοποιείται:** επιλεκτική σύνθεση Draft Menu με επαναχρησιμοποίηση ERP δομών. **Πότε δεν χρησιμοποιείται:** ενημέρωση/διαγραφή ERP Catalog, τιμολογιακή πολιτική, POS, δημοσίευση ή παραγωγικές εργασίες.
